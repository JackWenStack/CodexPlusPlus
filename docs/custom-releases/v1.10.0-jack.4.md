# 1.10.0-jack.4

修复三个 renderer 性能问题：

- 会话视图缓存正文和输入框节点，忽略侧栏、消息内部及无关弹层变更；节点替换、移动和布局变化仍会更新。连续两帧稳定即停止对齐，最多保留 16 帧用于布局收敛。
- 皮肤关闭后的清理只执行一次。重新启用或出现新的外部皮肤运行时后，下一次关闭仍正常清理。
- 撤销旧版本的全局 `Array.prototype.filter` 补丁，扩展插件继续走专用请求/响应与独立目录接口。热更新时恢复原生筛选，也不会覆盖其他扩展的筛选实现。

在 Edge 155 的 1 万内容块隔离场景中，持续修改无关侧栏的 1.2 秒内，对齐从 197 次降到 3 次，目标查找为 1 次；关闭皮肤后的 25 次刷新全页清理次数由 25 次降到 0 次。首次关闭仍执行一次兼容清理。

当前本机官方 Codex 26.730.8199.0 的原生插件查询实测：撤销全局补丁前后均为 581 个，插件 ID 集合一致。旧版官方客户端的兼容性未穷举；这些隔离指标不代表整机帧率或所有会话的性能。

验证：前端 750 项通过、1 项既有跳过；核心 CDP 回归 170 项通过；插件传输适配 14 项、发布元数据 3 项通过。类型检查、Windows release 构建及隔离 WebView 的版本/导航验收通过，真实浏览器覆盖节点替换、流式内容、窄窗口和开关恢复。
