# Codex++ JackWen 1.10.0-jack.1

基于上游 `cf30215583f306c1a590c750e30c2dcdee8c39d8`，包含 v1.10.0 发布后的修复。

- 复用上游 Windows 可写句柄刷盘修复，解决删除备份时的 `os error 5`。
- 默认保留历史删除备份，不自动启用上游新增的过期备份回收。
- 修复 Windows 会话文件在扫描后被占用时的同步中止，跳过占用文件并继续处理可写文件。
- 兼容 26.730 桌面端的 `app-initial` 原生接口及新版 signals 模块，删除成功后同步原生会话缓存。
- 保留上游删除行隐藏兜底，撤销后解除隐藏并同步恢复；刷新有超时，不强制重载窗口。
- 保留删除确认，修复被主题底色覆盖成全黑的遮罩，使用透明磨砂效果。
- 使用独立的 Fork 更新通道，支持 `jack.N` 修订版本比较。

Windows 提供 NSIS 安装包、便携 ZIP、更新元数据和 SHA-256 校验文件。沿用现有应用标识和用户数据路径，以便覆盖升级；回滚程序时不会主动恢复或删除会话数据。
