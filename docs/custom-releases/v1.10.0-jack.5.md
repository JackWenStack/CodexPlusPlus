# 1.10.0-jack.5

Dream Skin 开启时，正文的 `textContent` 更新会触发整页皮肤结构检查，即使没有任何部件或结构标记需要更新。本版只过滤全部由文本/注释节点增删组成的变更；元素新增、删除和结构属性变化仍执行上游原有检查。

上游皮肤脚本、CSS、图片及主题配置保持原样。定制补丁位于 `assets/inject/dream-skin-mutation-filter.js`，仅在生成 Dream Skin 运行代码时应用；其他皮肤引擎不应用该补丁。上游匹配位置变化时保留原行为，并由契约测试报告适配漂移。

使用本机当前背景图、主题配置和样式，在独立 Edge 对比正文、文字更新、新段落/代码块、表格、新消息、弹窗、输入框替换、首页及设置页。九个场景的皮肤标记、计算样式和几何信息一致；截图仅允许极少数像素的单色阶合成舍入差异，没有可辨认的视觉变化。

约 1.5 万元素、12 次文字更新的隔离测试中，整页部件/结构条件检查由 12 次降到 0 次；新元素仍执行原有检查，因此本版未解决新增段落触发整页扫描的全部开销，也不代表整机帧率提升。

验证：前端 754 项通过、1 项既有跳过；核心注入/皮肤/上游资源校验共 186 项通过、1 项既有忽略。类型检查、Windows release 构建和隔离 WebView 版本/导航验收通过。
